率土战场客户端 0.2.8 · Windows x64 通用账号安装

1. 在新电脑安装并登录游戏，停在普通地图。
2. 运行 STZB-Battlefield-Desktop-Setup-x64.exe，点击「安装并打开」。可选择 F 盘目录。
3. 首次缺少采集驱动时，会打开随包附带的官方 Wireshark 安装程序。请保留 Npcap 选项，自行确认许可、管理员或重启提示。
4. 客户端自动核对当前角色、区服和赛季，匹配对应赛季资料。不需要填写账号、密码、角色、区服或赛季。

已登录身份直读当前针对大神桌面版 Android x86_64 验证。
PC 官服提供自动检测和兼容入口；客户端版本或运行权限未通过身份核对时会停止采集并显示原因，不会用安装包里的角色替代。
MuMu、雷电、手机及 Windows ARM64 不在本安装版的验证范围。

客户端、Python、图像运行库、解析器、武将/战法/兵种/武器目录和后台补报组件随包携带。

战报读取检查：只对当前账号的已观测记录补齐资料。明确过期或无权读取的编号停止自动重试，重开后仍保留；未确认查询范围或普通超时不直接判为过期。最新战报和其他队伍继续采集，本地已有战报及统计数据保留。
安装版使用同一套采集、最新阵容与主力判定、战报查询代码，不使用旧精简安装模式。
安装包不携带示例账号、外交配置或赛季战报。每台电脑依据当前登录角色建立自己的档案。
普通势力、有盟/无盟、流浪军、有聚义/无聚义均按客户端身份自动切换统计口径。
换账号、区服或赛季时自动隔离档案；换盟或身份变化时自动切换关系配置和翻页进度。
有组织时自动读取成员名单；无组织时只按核实的本人身份统计，不合并其他无组织玩家。
启动时尚未登录，会持续等候并自动重连，不需要填写角色参数或重新安装。
新电脑从同盟战报和地图中继续采集可访问的数据；程序不能获得游戏服务器未向当前角色开放的记录。

目录：app-版本号 存放程序；Workspace 存放本机档案、自动识别配置、日志和断点。
重复安装保留 Workspace 和旧版本，不删除历史记录。
关闭窗口收到托盘；托盘退出客户端后，本机服务继续采集。需要停止时可运行该程序目录的 Start-Installed.ps1 -Workspace 对应Workspace路径 -Stop。
安装包尚未申请代码签名证书。下载后可对照交付的 SHA256 校验，不需要关闭系统防护。

结构化战报策略：持续获取武将、等级、红度、战法、兵力和结果；字段齐全后不再为了数字正文单独补采。已有正文保留，游戏回包附带的正文仍正常归档。
