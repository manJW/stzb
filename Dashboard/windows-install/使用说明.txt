率土战场看板 · Windows 本机安装

适用范围
Windows 10 / 11 64 位（Intel 或 AMD）。使用本机安装的率土之滨 PC 客户端。
本安装包含看板和它自己的 Python 运行环境，正常使用不需要另外安装 Python。

首次使用
1. 先安装并打开官方 PC 游戏。
2. 双击 STZB-Observer-Setup-x64.exe。区服填写游戏显示的区服号；赛季填写用于区分档案的本地标识。
   同一个档案在其他电脑上也用相同的区服和赛季标识。
   游戏已运行时会填入当前程序路径；否则点“浏览”选择游戏目录里的 stzb.exe。
3. 若提示缺少 Wireshark / Npcap，按提示安装官方组件，保留 Npcap 选项。
   Windows 可能要求管理员确认，按官方安装界面继续。若提示重启，请重启后再打开看板。
4. 浏览器打开战场看板后，切回游戏。若已在地图，可先在主城附近拖动地图，等看板收到本人资料更新。
   看板仍在等待角色时，回角色选择后重新进入一次即可补读登录信息。
5. 需要来袭提醒时，在“观察设置”里标记你已确认的敌对同盟。
   在游戏里打开战报或翻页，客户端实际发来的战报会被保存。

以后使用
双击桌面的“率土战场看板”快捷方式。关闭浏览器后仍会采集。
开始菜单里有“率土战场看板 - 停止”，用于关闭本机看板。
重装新版时可先停止看板，旧档案仍保留。换区服、赛季或角色请使用新的档案目录。

功能与数据
安装版包含实时地图、来袭预警、已接收战报的归档和查询。
自动补战报、快捷驻守和成员接收在本机通用安装版关闭。
看板仅在本机访问。程序和资料默认在 %LOCALAPPDATA%\STZB-Observer。
Workspace 目录保存本机档案和设置，Exports 目录保存看板导出。
安装包使用空档案。当前电脑里的角色配置、战报库和游戏文件不随包迁移。
