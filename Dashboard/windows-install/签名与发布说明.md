# Windows 签名与发布

0.2.7 的安装版和免安装版共用原生启动入口，直接启动内置 Python 后台。
安装目录和 Workspace 分开；升级只正常关闭本目录的旧服务，不删除用户数据。
旧版 PowerShell 启动入口仅保留兼容配置和手动维护用途，客户端不再调用它启动后台。
系统进程发现和旧版进程归属核对仍可能使用只读系统查询。

## 当前签名状态

本机未发现可用的代码签名证书及其私钥，也未发现 SignTool。
本轮发行包明确标为未签名；SHA-256 和杀毒扫描不能代替受信任的数字签名。

正式签名还需要：

1. 经可信颁发机构验证的发布者身份，以及代码签名证书或已完成身份核验的云签名服务。
2. 对应私钥的授权使用方式，例如本机证书存储、硬件令牌或受控云签名服务。
3. Windows SDK 的 SignTool 或签名服务客户端，以及 RFC 3161 时间戳服务配置。

私钥、令牌和密码不提交到仓库，也不写进公开说明或日志。
签名应在生成文件校验清单之前完成；最后再签安装器并生成发行包 SHA-256。
已有可信签名的 Python、Wireshark 等第三方组件保留原签名。
签名后仍应核对发布者、证书链、时间戳及全部发行文件的哈希。
签名不能保证新版本立刻免除下载信誉提示。

## 发布和下载核对

源码提交保持在现有 main 历史之后，SharedData 分卷保持原内容和路径。
正式安装 EXE、免安装 ZIP 和 SHA256SUMS.txt 发布到 GitHub Releases。
发布后重新下载两份发行文件，核对 SHA-256、解包完整性、模块与源码的一致性，
并在含中文和空格的独立目录验证启动、角色识别及正常退出。
