# 率土同盟视野试跑

## 盟友电脑

1. 使用 Windows 版率土之滨官服。安装 [Python for Windows](https://www.python.org/downloads/windows/)（Python 3.10 或以上）、[Wireshark](https://www.wireshark.org/download.html)（安装时保留 Npcap）、[Tailscale](https://tailscale.com/download/windows)。登录自己的 Tailscale 账号并接受看板主机的私有设备邀请。
2. 解压试跑包，保留 `Dashboard` 文件夹。双击 `Dashboard\启动成员采集.cmd`，按提示拖入看板管理员单独发来的邀请 JSON 和游戏目录里的 `stzb.exe`。默认安装的 Wireshark 会自动识别。自定义安装时按提示拖入 Wireshark 目录里的 `dumpcap.exe`。
3. 确认邀请显示的角色和区服正确。先开采集再登录受邀角色，进入主城附近地图，等窗口提示地图角色与本盟身份已核对。接着查看一处有行军的战区，打开游戏内同盟战报，翻 2～3 页并打开一份完整战报。窗口显示接收端已确认入库后，告知管理员。
4. 每次进入不同战区，都可上报客户端实际收到的队伍动态。按 `Ctrl+C` 停止采集。暂时断网时，最多保留最近 24 小时、3,000 条待发记录。

邀请文件能授权上报，请只交给对应盟友。采集端读取地图队伍和可读的本盟战报，游戏账号登录仍在游戏里完成。

## 看板主机

1. 启动现有看板。接收服务在主机的 `127.0.0.1:8788`，看板仍通过 `127.0.0.1:8787` 打开。
2. 登录 Tailscale。为两位试跑成员分享此设备，在访问规则中仅放行接收端口 `8443`。若首次启用 Serve，按 Tailscale 提示启用本私有网络的 HTTPS 证书。运行下列命令，并记下输出的 `https://…ts.net:8443` 地址。[Tailscale Serve 命令](https://tailscale.com/docs/reference/tailscale-cli/serve) · [设备分享说明](https://tailscale.com/docs/features/sharing)

   ```powershell
   tailscale serve --bg --https=8443 http://127.0.0.1:8788
   ```

3. 在看板主机按游戏内昵称生成个人邀请。盟友须与你同服、同赛季、同盟。若本机档案没有唯一角色编号，在主机游戏中查看这位盟友所在的地图区域后再生成。邀请写到 `F:\STLab\Exports`，由管理员私下发给本人。

   ```powershell
   & 'C:\python310\python.exe' 'F:\STLab\Dashboard\member_receiver.py' invite '盟友游戏昵称' 'https://你的主机名.ts.net:8443'
   ```

4. 先让两端打开同一片战区和同一份本盟战报。在看板的「行军链路」「交战记录」确认同一记录出现两个来源和各自时间。再让盟友打开另一个战区，确认新行军来自该盟友。默认筛选为已确认敌盟，查看本盟行军时把阵营切到本盟或全部。
5. 停用个人邀请时在看板主机运行下列命令。历史来源留在已归档的记录上。重新生成邀请会使同角色的旧邀请失效。

   ```powershell
   & 'C:\python310\python.exe' 'F:\STLab\Dashboard\member_receiver.py' revoke '盟友游戏昵称'
   ```
